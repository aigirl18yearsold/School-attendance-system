# School-attendance-system
Attendance and student performance management system built using Python and SQLite.

A student attendance and performance management system built using Python and SQLite.

- Student management
- Attendance tracking
- Monthly reports
- Yearly reports
- Percentage calculation
- Pass/fail analysis
- Top student ranking

- SQLite
